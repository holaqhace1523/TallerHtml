# Taller HTML5 + CSS

## Objetivo

Construir una página web para la venta de motocicletas, utilizando HTML5 y CSS3. El sitio permite mostrar diferentes modelos de motos organizados por categorías y cuenta con una sección de información de la empresa y un formulario de contacto.

## Variante asignada

**Contexto:** Página web para una empresa dedicada a la venta de motos de baja hasta alta cilindrada.

**Restricción visual:** Diseño basado en los colores negro, rojo y blanco, buscando una apariencia llamativa y relacionada con el mundo de las motocicletas.

**Requisito técnico:** Utilizar HTML5 semántico, CSS externo y Flexbox para organizar las tarjetas de las motocicletas y adaptar el contenido a diferentes tamaños de pantalla.

## Tecnologías

HTML5, CSS3, Git y GitHub.

## Cómo ejecutar

En este caso usamos una extención llamada live server lo cual facilitaba la revision del archivo en tiempo real, pero tambien podemos usar start index.html en la terminal de Visual Studio Code.

## Decisiones de diseño

1. Se utilizaron los colores negro, rojo y blanco para darle al sitio una apariencia relacionada con las motocicletas y mantener una identidad visual uniforme.

2. Se utilizó Flexbox para organizar las tarjetas de las motos. Esto permite que las tarjetas se acomoden automáticamente dependiendo del espacio disponible.

3. Se agregaron imágenes de las motocicletas dentro de las tarjetas para que cada modelo pudiera identificarse visualmente y hacer mas interesante la venta de cada producto.
